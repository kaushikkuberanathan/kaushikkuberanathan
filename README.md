## Featured Product: Dugout Lineup

### A mobile-first lineup and game-coordination platform for youth baseball and softball

🌐 **Live Product:** [dugoutlineup.com](https://dugoutlineup.com)
📦 **Repository:** [github.com/kaushikkuberanathan/lineup_generator](https://github.com/kaushikkuberanathan/lineup_generator)

Dugout Lineup began with a real problem I experienced as a youth baseball coach:

> How do you create a fair, development-focused lineup quickly—while managing player preferences, position variety, bench rotations, league rules, absences, and game-day pressure?

Most volunteer coaches solve this using paper, memory, spreadsheets, or group texts. Dugout Lineup turns that fragmented process into one clear, mobile-first workflow.

### What the Product Does

* Generates constraint-aware defensive lineups
* Assigns positions inning by inning
* Supports fair bench rotations
* Provides manual overrides and lineup validation
* Manages batting orders and player statistics
* Displays lineups using a mobile-friendly Diamond View
* Imports schedules from images or pasted text
* Generates printable lineup cards
* Creates read-only share links for parents, assistant coaches, and scorekeepers
* Works offline through synchronized cloud and local storage
* Installs as a Progressive Web App on iOS and Android

### Product Principles

Dugout Lineup is designed around a few simple principles:

* Coaches must be able to use it under real game-day pressure
* Fairness should be built into the system
* The product should explain warnings rather than silently fail
* Parents and scorekeepers need visibility without editing access
* Technology should reduce cognitive load, not introduce more administration
* Human judgment remains more important than automated recommendations

### Product and Technical Architecture

* **Frontend:** React and Vite Progressive Web App
* **Backend:** Node.js and Express
* **Data:** Supabase with localStorage offline resilience
* **Hosting:** Vercel and Render
* **Automation:** GitHub Actions
* **AI:** AI-assisted schedule parsing and product development workflows
* **Quality:** Unit tests, integration tests, smoke testing, release checklists, and deployment monitoring

### Product Operating System

The repository is managed as a real product—not just a code experiment.

It includes:

* Product charter
* Personas
* Prioritized roadmap
* Release history
* Solution architecture
* Structured bug, story, and technical-debt templates
* Product and persona labels
* Pull-request ship gates
* Overnight development-environment soak requirements
* Version management
* Product board workflow
* Production monitoring
* Documentation and release governance

### Why This Project Matters

Dugout Lineup demonstrates what becomes possible when domain expertise, product judgment, and AI-assisted development work together.

It is not about replacing engineering judgment with prompts.

It is about a product leader being able to move more directly from:

**Observed problem → customer insight → product strategy → interaction design → technical architecture → working product → real-world learning**

The product is also deeply personal. It combines my interests in product building, youth development, coaching, fairness, family, and community.
