## Featured: Dugout Lineup

**A mobile-first lineup and game-coordination platform for youth baseball and softball.**

🌐 [dugoutlineup.com](https://dugoutlineup.com) · 📦 [lineup_generator](https://github.com/kaushikkuberanathan/lineup_generator)

Built to solve a problem I have every week as a coach: build a fair, constraint-aware lineup — bench rotations, position variety, absences, league rules — in under two minutes before first pitch. It's AI-assisted product development, not a prototype: production Supabase backend, PR ship gates, release governance, and real users.
